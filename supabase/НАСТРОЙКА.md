# Настройка Supabase для обновления «друзья + push + почта»

Делать один раз, по порядку.

## 1. База: друзья и push
SQL Editor → New query → вставить весь файл `supabase/friends_push.sql` → Run → «Success».

## 2. Серверная функция send-push
1. Edge Functions → **Deploy a new function** → **Via Editor**.
2. Имя функции: `send-push` (точно так).
3. Стереть пример и вставить весь файл `supabase/functions/send-push/index.ts` → **Deploy**.
4. Открыть функцию → **Details** (или Settings) → выключить **Enforce JWT Verification** → Save.
5. Проверка: через ~20 секунд в Table Editor → таблица `app_secrets` должна появиться строка `vapid_public`.

## 3. Ссылка из письма ведёт на наш сайт
Authentication → **URL Configuration**:
- Site URL: `https://ghost-mode-7ezo.onrender.com`
- Redirect URLs → Add URL: `https://ghost-mode-7ezo.onrender.com/**`

## 4. Красивые письма
Authentication → **Emails** → Templates:
- **Confirm signup** — Subject: `Подтверди почту — Ghost Mode`, тело: файл `supabase/email/confirm-signup.html`.
- **Reset password** — Subject: `Новый пароль — Ghost Mode`, тело: файл `supabase/email/reset-password.html`.

## 5. (Рекомендуется) Своя почта для писем
Встроенная почта Supabase отправляет очень мало писем в час — при наплыве регистраций письма перестанут приходить.
Project Settings → Authentication → **SMTP Settings** → включить Custom SMTP и указать почту Ghost Mode
(для Gmail нужен «пароль приложения», для Яндекса — пароль приложения в настройках Яндекс ID).
