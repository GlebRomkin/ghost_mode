# GM — Ghost Mode

Ежедневник с делами, статистикой, фокус-таймером, альбомом мыслей и достижениями.
Разработано [Veraxis](https://veraxis-h0kw.onrender.com/).

## Структура

```
index.html          — разметка страницы
css/styles.css      — все стили (тёмная тема Ghost Mode)
js/core.js          — хранилище данных, даты, экран «День», список дел
js/stats.js         — статистика: динамика, дела по дням, активность, дни недели
js/profile.js       — профиль, аватары, 50 достижений, альбом, уведомления, напоминания
js/main.js          — боковые панели (серия, календарь, заметки), таймер фокуса, запуск
assets/             — иконка GM и логотип Veraxis
GM.ico, GM-logo.png — иконка для ярлыка и логотип в большом размере
render.yaml         — настройки для Render
```

Скрипты подключаются по порядку: core → stats → profile → main.
Сервера пока нет: данные хранятся в браузере (localStorage). Серверная часть
(аккаунты, огоньки, общий альбом) появится отдельной папкой `server/`.

## Публикация на Render

1. Залить эту папку в репозиторий на GitHub.
2. На render.com: **New → Static Site** → выбрать репозиторий.
3. Build Command — оставить пустым, Publish Directory — `.`
4. Deploy. После каждого `git push` сайт обновляется сам.

(Либо **New → Blueprint** — Render сам возьмёт настройки из `render.yaml`.)
